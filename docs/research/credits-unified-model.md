# 各家大模型厂商 Credits/套餐数学建模（统一框架）

> 来源: 各厂商官方文档（docs/{deepseek,mimo,minimax,qwen}/）+ 用户真实账单（/home/yanli/文档/deepseek/）
> 日期: 2026-08-07
> 锚点: DeepSeek（人民币直计，无积分体系）→ 各厂商积分本质 = 人民币的整数化缩放

## 一、核心洞察

**所有厂商的"Credits/积分/额度"最终都可以换算回人民币**。以 DeepSeek 的
人民币直计为锚点，建立统一换算：

| 厂商 | 积分单位 | 换算率 | 计费维度 | 状态 |
|---|---|---|---|---|
| **DeepSeek** | 无（人民币直计） | 1 元 = 1 元 | token | ✅ 标准锚点 |
| **MiMo** | Credit | 1 Credit = 1e-8 元 | token | ✅ 已建模 |
| **MiniMax** | 积分 | 1 积分 = ¥0.007 | token | ✅ 本次建模 |
| **Qwen (Token Plan 个人版)** | Credits | 模型分档抵扣系数 | token | ✅ 本次修正（8/7 实测） |

## 四、MiniMax（1 积分 = ¥0.007）

### 积分兑换规则（官方 faq）

> **1,000 积分 = ¥7**，与开放平台 API 按量付费目录价等值。
> 使用已购积分调用资源时，按该资源的目录价折算为积分扣减。

**积分 = 按量目录价（元/1M tokens） ÷ 0.007**

## 五、Qwen（Token Plan 个人版，Credits 积分制）

**实测确认（2026-08-08）**：用户 qwen-responses 的 API Key 前缀 `sk-sp-` + Base URL `token-plan.cn-beijing.maas.aliyuncs.com` = **阿里云百炼 Token Plan 个人版专属端点**（Credits 积分制），**不是** Coding Plan（按请求次数）。

### Token Plan 个人版套餐（月付，官方 2026-07 上线）

| 档位 | 价格 | 每 5 小时限额 | 每 7 天限额 | 并发 Agent | 相对 Lite |
|---|---|---|---|---|---|
| Lite | ¥39/月（原价 ¥60） | 700 Credits | 2,500 Credits | 1-2 个 | 1x |
| Standard | ¥139/月（原价 ¥180） | 3,000 Credits | 10,000 Credits | 3-4 个 | 4x |
| **Pro**（用户当前档） | **¥499/月**（原价 ¥600） | **12,000 Credits** | **40,000 Credits** | 6-8 个 | 16x |

- 5 小时窗口：自首次调用起滚动，累计达限暂停服务，窗口结束重置（当前限时取消限制）
- 7 天窗口：自首次调用起计时，累计达限暂停服务，满 7 天重置；窗口内未用完不结转
- 专属凭证：`sk-sp-` 开头 Key + `https://token-plan.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`
- ⚠️ 用普通百炼 `sk-` Key + 通用域名**不抵扣套餐额度**，会走按量计费

### Credits 抵扣公式（官方）

```
单次请求 Credits = (命中缓存输入 Tokens × 命中系数 + 未命中输入 Tokens × 未命中系数 + 输出 Tokens × 输出系数) / 1,000,000
```

## 六、统一换算速查（以 DeepSeek 为锚）

**把任意厂商消耗换算成"等值人民币"**：

```
DeepSeek:   成本 = hit×0.02/0.025 + miss×1/3 + out×2/6（¥）
MiMo:       成本 = credits × 1e-8（¥）  [credits 直接读响应 usage]
MiniMax:    成本 = 积分 × 0.007（¥）
Qwen TP:    成本 = (hit×ch + miss×cm + out×co)/1e6 Credits（Pro 档 40,000/7d）
```

### 模型分档对比（2 级梯度是主流）

| 厂商 | 快模型 | 旗舰模型 | 价格比（快:旗舰） |
|---|---|---|---|
| DeepSeek | flash 0.02/1/2 | pro 0.025/3/6 | 1:3 (miss/out) |
| MiMo | v2.5 2/100/200 C | pro 2.5/300/600 C | 1:3 |
| MiniMax | M2.7 2.1/8.4 | M3 2.1/8.4（五折后）| ~1:1 |
| Qwen TP | max 旗舰高系数 | preview 1 折/0.2 折 | 折扣主导 |

## 七、Reasonix 意义

1. **MiMo/MiniMax 代码价格表已正确**：mimo（0.02/1/2、0.025/3/6）、minimax（M3 2.1/8.4/0.42）无需修改。
2. **用量统计准确**：`Usage.CacheHitTokens / CacheMissTokens / OutputTokens` × 价格表 = 真实扣费。
3. **Credits 显示**：如需 UI 显示 Credits，MiMo 用 `费用 × 1e8`、MiniMax 用 `费用 ÷ 0.007`。
4. **黑盒已拆解**：
   - MiMo 页面 Credits = 人民币 × 1e8
   - MiniMax 积分 = 按量价 ÷ 0.007
   - Qwen Token Plan Credits = (hit×ch + miss×cm + out×co)/1e6（Pro 档 40,000/7d）
5. **新增厂商建模流程**：查按量目录价 → 找积分兑换率（通常是"目录价折算"）→ 建立换算 → 验证代码价格表。
