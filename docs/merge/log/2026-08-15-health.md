## 二、开发版遇到的问题（经验——预览/稳定版参考）

### 1. 滚动卡顿（#8200 域）——🟡 已缓解
- **根因**：虚拟化行挂载巨型 markdown DOM（每帧重建）——非"加载历史太多"
- **修复**：超长回答折叠预览（>2000 字符 → 400 字符预览 + 展开）——行内 useState 可靠交互
- **经验**：虚拟化是分页机制（只渲染视口）——但行高估算偏差/巨型行挂载是卡顿主因

### 2. 输出闪烁（#8845 域）——🟡 已加固
- **根因**：上游 #8760 滚动状态机——流式行增长时 Virtuoso 发布 atBottom=false 竞态
- **修复**：isPinned 竞态保持 + rAF 合并（d4f31bc42）——本地加固与上游共存
- **经验**：上游滚动重构（#8760）有回归风险——本地必须有竞态兜底

### 3. 折叠交互 bug（展开无反应）——✅ 已修
- **根因**：全局 foldMap 闭包 + 虚拟化行身份问题
- **修复**：行内 useState（组件自管展开态——与行身份无关——必响应）+ 整行可点
- **经验**：虚拟化行的 UI 状态必须行内管理（全局 map 在虚拟化下不可靠）

### 4. 渲染性能无遥测——✅ 已补
- **根因**：卡顿反馈无数据可查（主观）
- **修复**：renderingPerf（longtask 60s 聚合）+ 启动 ping 链路验证 + uiPerf 已有 dom_nodes/frame
- **经验**：性能反馈必须有遥测佐证（count/max/avg——事后可诊断）

### 5. 执行模式重构（#8866）——⚠️ 观察期
- **影响**：轻量/均衡/交付模式被"自适应标准"取代——deliveryProfile 死代码清理
- **经验**：上游大语义重构（209 文件）——需观察期验证行为（未进稳定版前）
