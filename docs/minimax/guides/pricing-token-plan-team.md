# Token Plan 团队版

> 了解团队中 Token Plan 席位、共享积分和按量计费资源的使用方式。

Token Plan 团队版适用于团队中的多成员协作。团队 Owner 可以购买 Token Plan 席位和积分池，成员通过各自的订阅 Key 使用被分配或共享的资源。

## 团队

团队用于多人协作：

* 团队 Owner 可以购买 Token Plan 席位。
* Token Plan 席位按 **1:1** 分配给成员。
* 成员通过自己的订阅 Key 使用被分配套餐的额度。
* 订阅可以在计费周期中途重新分配；重新分配不会重置用量，新被分配者继承当前订阅的用量状态。

## 共享积分

团队可以使用共享积分池：

* 团队 Owner 为积分池购买积分。
* 成员通过自己的订阅 Key 消耗共享积分。
* 未被分配 Token Plan 的成员，只要积分使用权限开启，也可以使用共享积分。
* Owner 和 Admin 可以管理成员对共享积分的访问权限。

## 按量计费

按量计费与 Token Plan、积分相互独立：

* 按量计费 API Key 与订阅 Key 相互独立。
* 每个团队有自己的开放平台钱包余额。
* 在某个团队中创建的按量计费 API Key 会消耗该团队的钱包余额。
