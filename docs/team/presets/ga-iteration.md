# 生物种群遗传算法框架（docs/team/presets/ga-iteration.md）

> **生物种群式 GA**（用户明确要求）：不是"配置参数搜索"——是**智能体种群进化**。
> 种群 = 一群智能体（个体，基因=预置配置/行为策略变体），通过选择/交叉/变异/适应度
> 逐代进化，优胜者成为下一代预置。**团队功能本身就是 GA 执行引擎**。

## 一、生物隐喻 ↔ 团队功能映射

| 生物概念 | 团队实现 | 说明 |
|---|---|---|
| 种群（population） | `/team-spawn N` 生成的 teammate 群体 | 每个个体带不同"基因"（预置变体） |
| 个体（individual） | 一个 teammate + 其预置配置 | 基因 = prompt/tools/effort/worktree 变体 |
| 基因（gene） | 预置配置的某个可变维度 | prompt 变体/工具集/effort/并行度 |
| 适应度（fitness） | metrics.md 6 维度加权 | 成功率/耗时/成本/前缀命中 |
| 选择（selection） | 适应度排序保留 top-k | 精英保留（top 20%）+ 锦标赛 |
| 交叉（crossover） | 两优胜配置合并（prompt×tools） | 产生后代个体 |
| 变异（mutation） | 单基因扰动（effort/并行度） | 探索新空间（S 位点禁变异） |
| 世代（generation） | 迭代轮（R1-R10 每轮一代） | 每代 = 种群评估 + 进化 |
| 优胜者（elite） | 适应度最高配置 → 预置库保存 | 下一代复用（preset vN+1） |

## 二、进化循环（用团队功能执行）

```
每世代（一轮迭代）：
1. 生成种群：/team-spawn N <prefix>（N 个变体 teammate，各带预置变体基因）
2. 并行评估：/team-add ×N（同基准任务，并行执行）
3. 采集适应度：metrics（成功率/耗时/成本/命中——每个体独立打分）
4. 选择：适应度排序，精英保留 top 20% + 锦标赛 k=2
5. 交叉：两精英配置合并（prompt×tools 交换）
6. 变异：新个体单基因扰动（effort/并行度——S 位点禁变异）
7. 淘汰：低适应度个体解散（/team-remove）
8. 优胜 → 预置库（preset vN+1，parent+mutation_source 标注）
9. 下一代 = 精英 + 后代 + 变异体
```

## 三、适应度函数（生物选择压力）

```
fitness(个体) = 0.4·成功率 + 0.2·(1/耗时) + 0.2·(1/token成本) + 0.2·前缀命中率
```

**选择压力设计**：
- 精英保留（top 20%）——不让最优配置丢失
- 锦标赛（k=2）——随机抽 2 取优，保持多样性
- **淘汰抑制**：前缀字节变化/竞态/成功率骤降 → 立即淘汰

## 四、种群与世代参数（成本红线）

| 参数 | 值 | 理由 |
|---|---|---|
| 种群 N | 3-4（世代内） | 真实 API 成本 |
| 世代数 | R1-R10 每轮一代 | 10 轮 = 10 代 |
| 精英比例 | 20% | 保留最优 |
| 变异率 | 30%（N 位点） | 探索 |
| S 位点变异 | **禁止**（0%） | 前缀缓存红线（golden 门） |
| mock 前置 | 每代先 mock 验证机制 | 免费验证进化逻辑 |

## 五、与 devil's advocate 攻击的关系（修正记录）

- **A1 攻击**（"GA 是参数搜索伪需求"）——**针对的是 9 位点参数搜索式 GA**，成立
- **生物种群式 GA 不同**：种群个体是**完整智能体**（行为策略多样性），变异空间是预置配置的**组合**而非单参数点；前缀稳定由"S 位点禁变异 + golden 门"保证（不逐代打穿）；适应度用**更难的基准**（真实团队任务 + 细粒度指标）避免饱和
- **保留**：S/N 位点分类 + golden 门 + 成本红线（种群小、mock 前置）——这些是生物 GA 与 Reasonix 哲学的结合点

## 六、防虚假完成自检

| 检查 | 判据 |
|---|---|
| 每代必有评估 | results.jsonl 行数 == 种群数 |
| 每代必有进化 | 下一代配置 ≠ 上代（至少 1 交叉/变异） |
| 优胜必有证据 | fitness delta 记录（vs 父代） |
| 缓存红线 | S 位点零变异；golden 字节对比每代 |
| 预置确实进化 | preset vN+1 的 fitness > vN 或标注保留理由 |
