## 二、4320 模式编码（6 维 3 态基因 = 太玄经 3 进制）

每个预置智能体 = 6 维坐标（每维 3 态，对应 T⁶ 的 6 轴）：

| 轴 | 维度 | 3 态（0/1/2） |
|---|---|---|
| v₀ | 任务类型 | 写 / 读 / 审 |
| v₁ | 领域 | 代码 / 数据 / 创作 |
| v₂ | 复杂度 | 简单 / 复杂 / 极复杂 |
| v₃ | 行为策略 | 分析 / 执行 / 优化 |
| v₄ | 交互模式 | 独立 / 协作 / 监督 |
| v₅ | 输出形式 | 代码 / 报告 / 证明 |

- **729 组合**（3⁶）→ 所有理论预置
- **×6 轨道** → 每个组合的 6 种演化方向（同模式不同视角）
- **−54 规范** → 等效表述去重（如"代码审查"与"代码评审"是同轨 2 点）
- **4320** → 有效预置模式空间

## 四、应用（元认知体系落地）

1. **预置库的数学分类学**：每个预置标注 6 维坐标——避免重复造模式（同坐标 = 规范等价，应合并）
2. **进化/组合的数学基础**：GA 的变异/交叉 = 6 维坐标的移动/组合（坐标空间 4320 有界——变异不越界）
3. **覆盖度度量**：现有预置覆盖 4320 的哪些坐标区——缺什么模式一目了然（如"创作领域/证明输出"区未覆盖）
4. **规范去重**：进化产生的"新配置"先查坐标——同坐标直接合并（省适应度评估）
5. **元认知检索**：任务分类器输出 6 维坐标 → 查 4320 空间 → 最近邻预置
